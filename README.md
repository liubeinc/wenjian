# 文件格式转换站

图片 / PDF / 表格的格式转换工具，参照 [alltoall.net](https://www.alltoall.net/)，
但**文件不出本机** —— 所有转换都在你自己的浏览器里完成，不上传任何服务器。

## 直接用

打开 **https://liubeinc.github.io/wenjian/**

图片互转、PDF 编辑、表格转换都能用。

受浏览器安全策略限制，网页版**用不了本机服务**，所以「读 TIFF/ICO」
「输出 GIF/TIFF」「PDF 转图片」这几项是灰的 —— 这是正常现象，不是坏了。

## 下载到本机（功能完整）

把整个仓库下载解压，双击 `index.html` 打开，再双击 `启动服务.bat`，
上面那几项灰掉的功能就都能用了。

本机服务需要 `node.exe`（仓库里没带，89 MB 太大）：用系统已装的 Node.js，
或去 [nodejs.org](https://nodejs.org) 下个便携版放进文件夹。

## 能转什么

| 类别 | 功能 |
| :--- | :--- |
| 图片 | PNG / JPG / WebP / GIF / BMP / AVIF / HEIC（苹果手机拍的）互转，可出 ICO 图标；可调质量、尺寸，支持批量 |
| PDF | 合并、拆分、选页重排、旋转、图片合成 PDF、改标题作者；转 JPG / PNG（需本机服务） |
| 表格 | Excel / CSV 互转，可出 CSV / JSON / HTML / TXT；多工作表分别导出；CSV 编码可选 UTF-8 / GBK |

## 为什么不用现成的在线转换站

日常要处理健康证、管控表这类含员工个人信息的文件，传到公网转换站既不合规也不安全。

所以这个工具的第一原则是**文件不出本机**：能纯浏览器做的就在浏览器做
（零上传、断网可用、无大小限制），浏览器做不到的（TIFF/ICO 解码、GIF/TIFF 编码、
PDF 按原生像素出图）交给一个只监听 `127.0.0.1` 的本机小服务。

几个实现上花了功夫的地方：

- **长数字不会被改**：18 位的身份证号 / 健康证号，Excel 和多数转换工具会因双精度
  浮点静默改掉末位（`...1234` 变 `...1260`）。这里只在能证明无损时才转成数字。
- **CSV 编码**：老系统导出的 GBK 文件会自动识别，也可以手动指定。
- **HEIC**：内置 WASM 解码器，苹果手机拍的照片不用转格式就能直接转。
- **降级有交代**：本机服务没启动时，界面上会说明哪几项做不了、为什么、怎么办，
  而不是让按钮点了没反应。
