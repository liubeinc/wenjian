文件格式转换站 · 使用说明
========================================

怎么用
------
双击文件夹里的网页文件（本机版叫「转换站.html」，从 GitHub 下载的版本叫
「index.html」），用浏览器打开，全部功能就在这一页里。
把文件拖进去，选要转成什么，点「开始转换」。

如果你是在 GitHub 上直接开的网页版，那就不用下载 —— 但网页版用不了
「本机服务」，见下一节。


关于「本机服务」（可选，不装也能用）
------------------------------------
大部分转换不需要它。但下面这几项浏览器自己做不了，要额外启动一个本机小服务：

  · 读 TIFF / ICO 图片
  · 输出 GIF / TIFF
  · PDF 转成图片（按原始清晰度出图）

需要的话：双击「启动服务.bat」，会弹出一个黑窗口。
那个窗口开着服务才在跑，用完直接关掉窗口就行。

启动服务后回到网页，点一下右上角的状态标签（显示「纯浏览器模式」那个），
它会变成「增强模式已就绪」—— 不用刷新页面。

★ 注意：如果网页是从 GitHub 上打开的（网址以 https:// 开头），
  上面这几项【永远】用不了，界面上会一直是灰的。这是浏览器的安全策略 ——
  公网上的网页不允许访问你电脑里的服务，属正常现象，不是坏了。
  想要这几项功能，把整个仓库下载到本机解压，再双击里面的网页文件打开。

本机服务需要 node.exe。仓库里没带（89 MB，太大），可以：
  · 用系统已装的 Node.js（有的话启动脚本会自动找到）
  · 或去 https://nodejs.org 下个便携版，把 node.exe 放进本文件夹


目录里都是什么
--------------
网页本体          双击这个用（本机版叫 转换站.html，下载版叫 index.html）
启动服务.bat      双击启动本机服务（可选）
转换服务.cjs      服务的程序本体，不要双击它
转换核心.ps1      真正干活的转换引擎，不用管
libs\             四个本地库文件（PDF、表格、压缩、HEIC），不要删
_临时\            转换过程中的临时文件，可以随时删


都能转什么
----------
图片：PNG / JPG / WebP / GIF / BMP / AVIF / HEIC（苹果手机拍的）互转，
      也能出 ICO 图标；可调质量、尺寸，支持批量。
      注：HEIC 第一次转换要先下载解码库（约 1.4 MB），慢网下可能要等十几秒，
      之后就快了。库是按需加载的 —— 不碰 HEIC 就不会下载。
PDF ：合并、拆分、选页重排、旋转、图片合成 PDF、改标题作者，
      以及转成 JPG / PNG（这项要开本机服务）。
表格：Excel / CSV 互转，可出 CSV / JSON / HTML / TXT，多工作表分别导出。
      CSV 中文乱码时，把「编码」从「自动识别」改成「GBK」。


几点说明
--------
· 全程离线可用，断网也能转。
· 文件不上传、不外发，转换完临时文件会自动清掉。
· 转换结果只在页面内存里，关掉或刷新页面就没了 ——
  有没下载完的结果时页面会拦一下，记得先下载或打包。
· 长数字（身份证号、健康证号这类 18 位号码）会原样保留，不会被改掉末位。
· 如果服务窗口提示「端口 9761 已经被占用」，说明已经开着一个了 ——
  去任务栏找那个黑窗口接着用，不用再启动。
